# 2026 搜尋最佳化紀錄

內容更新：2026-09-12（台灣時間）。網站：https://yt.jamesboson.com/

## 策略與依據

網站是側影之心的真實舞蹈錄影作品集，主要用途是讓舞者、舞團、舞蹈教室及活動主辦方評估作品並洽詢合作。

本次以既有拍攝作品及服務描述為基礎，讓網頁內容、身份、語言與影片更容易被讀取及理解。Google 的 2026 AI 搜尋指引仍以可索引、有用、可信的原創內容和既有 SEO 基礎為核心；沒有加入專為排名而生的城市頁、虛構經歷、評論、地址、價格、llms.txt 或隱藏關鍵字。

## 已實作

- 繁體中文 `/` 與英文 `/en/` 均由完整靜態 HTML 提供，無需 JavaScript 才顯示翻譯。
- 兩語言各自 canonical，並有互相對應的 `zh-Hant`、`en` 和 `x-default`。
- 保留首頁分類與燈箱；作品連結可被爬蟲追蹤到獨立頁面。12 支影片各有中英文觀看頁，以一支可見的影片為主體，附作品、活動與拍攝者資訊，並有同類作品與合作連結。
- 觀看頁直接提供 YouTube iframe，不以點擊後建立 iframe 的方式隱藏播放器；不自動播放。使用 YouTube 隱私增強模式，但進入觀看頁仍會連線 YouTube。
- 每頁有個別標題、摘要及分享資料。沿用既有真實作品縮圖。
- 品牌身份以 `Person`、`WebSite` 表示；首頁用 `CollectionPage` / `ItemList`，作品頁用 `WebPage` / `VideoObject` / `BreadcrumbList`。沒有宣稱實體商家或官方主辦身份。
- VideoObject 的 `uploadDate` 採 YouTube 公開資料中的首次發布時間，含時區；影片長度採公開秒數。來源保存於 `content/video-metadata.json`，核對日為 2026-09-09。影片標題開頭的演出日期不當作上架日期。
- 不將 YouTube 觀看次數當成網站播放數。BOOMBAYAH 的 200 萬觀看標示附原數據日期，沒有將過時數字加入動態觀看統計。
- Sitemap 共 26 個標準網址，含 24 個影片項目與雙語對應；lastmod 記錄內容實際更新日，不在每次建置時刷新。
- 保留 404 的 noindex；robots.txt 開放公開內容與前端資源，排除維護資料夾。
- 沿用 WebP、圖片尺寸、首圖優先載入及非首圖 lazy loading。獨立播放器預留 16:9，減少版面位移。首頁與作品頁的 JS/CSS 使用內容雜湊，避免舊快取混入新版頁面。
- 舊語言 query URL 轉往標準路徑，保留其他參數與錨點；GA4 不記錄即將轉址的舊語言頁，正式頁保留原分析。

## 驗證

- `python scripts/check-site.py`：從靜態 HTML 檢查全部 26 頁的唯一標題、描述、單一 H1、自我 canonical、互相對應的 hreflang、連結可達性、內部連結／錨點／資源、影片日期與 JSON-LD、24 個影片 Sitemap 項目。
- `node --check app.js` 與 `node --check analytics.js`：語法檢查。
- 本機瀏覽器：中英文切換、分類、燈箱、作品頁、舊語言網址和 UTM 保留；沒有新 JavaScript 錯誤。
- 390px 手機 viewport：首頁與作品頁無水平溢出、影片顯示、導覽與內容可讀；測試後還原 viewport。
- 分析 smoke check：本機排除、正式中英文頁／作品頁載入分析、舊語言頁排除、作品與分類事件不變。
