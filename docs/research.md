# 作品集定位與設計依據

研究日期：2026-09-09。以公開網頁與實際瀏覽器檢視為依據，沒有使用或發布私人 YouTube Studio 數據。

## 頻道與價值

- [側影之心 YouTube](https://www.youtube.com/@jbs-street-recordings)：公開頁顯示 4.47 萬訂閱者、1,946 部影片、11,262,199 次觀看，所在地台灣，2023-02-28 加入。
- 頻道首頁、熱門作品與播放清單涵蓋 K-pop cover、街頭快閃、校園舞展與熱舞賽事，且多支作品標示 4K60fps。這些是網站服務分類與實際作品篩選的依據。
- 實際觀看《Strategy》Side Cam 與《ICONIC BY MISTAKE》片段，觀察到舞者表情、隊形與現場環境的紀錄；網站以舞蹈與現場演出攝影定位，不延伸宣稱婚禮、空拍、商業廣告、導演或大型製作團隊經驗。
- 核心價值主張「讓每一個動作，都被看見」是依頻道內容撰寫的品牌提案，不是從原頻道逐字引用的自介。
- 公開合作聯絡：[Instagram @jbs.street.recordings](https://www.instagram.com/jbs.street.recordings/)。頻道說明歡迎影片主角私訊領取原檔，並註明可能已刪除；FAQ 因而保留「依保存狀況」條件。
- 活動名稱與演出者名稱屬作品說明，沒有當作客戶名單、官方合作或代言宣稱。短片、原始素材、價格、機位與交期均保留在洽談時確認。

## 海外參考

1. [Squarespace 攝影模板集](https://www.squarespace.com/templates/browse/topic/photography)：實際檢視 Night、Mosley、McCurry、Keo、Gilden 等縮圖。採納大面積影像、節制導覽、清楚字級對比與留白；自行實作版面，沒有複製模板程式碼或照片。
2. [Jacob Jonas](https://www.jacobjonas.com/)：以大量舞蹈、影像與舞台專案建立作品導向的敘事；每件作品標註角色。本站採用「作品先行」及影片來源／演出資訊清楚標示的方式。
3. [Katrina McPherson](https://katrinamcpherson.com/)：舞蹈影像導演、攝影師與創作者，將作品、專業實踐、自介與聯絡入口清楚區分。本站採納由作品進入服務、再了解拍攝者的閱讀路徑。
4. [Gabriel Bienczycki](https://www.bienczycki.com/)：導演與攝影指導，其舞蹈背景、身體動作與舞台調度是自介的重要部分。本站聚焦對舞者與演出情境的觀察，不把其他人的資格或經歷移植到使用者身上。
5. [Benjamin Scot](https://www.benjaminscot.com/)：以簡潔的 Cinematographer / Photographer 定位與 DP reel 入口，讓來訪者直接接觸影片；啟發本站簡短定位與一鍵開啟影片的設計。

深炭黑、灰綠與淡萊姆色是本次自訂的視覺選擇。保留真實藍色舞台燈光與演出畫面，讓作品本身成為視覺主角。手機版改為單欄作品，影片只在點擊時載入。
